CampusFlow

Smart Campus Operations Platform

Problem

Campus service requests are often fragmented across different departments and communication channels. Students may not know where to submit an issue, who is responsible for it, or what its current status is.

Solution

CampusFlow provides a centralized platform where students can submit, track, and resolve campus service requests while staff and administrators can manage workloads and monitor campus operations.

Core Features

- Student service requests
- Staff request management
- Admin dashboard
- Request tracking
- Role-based access control
- Search and filtering
- Priority-based request management
- Notifications
- Campus operations analytics

Tech Stack

- React
- TypeScript
- Node.js
- Express
- PostgreSQL
- Python
- FastAPI
- WebSockets
- Docker
